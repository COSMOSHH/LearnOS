# LearnOS

面向个人学习、资料问答、自测复盘和面试准备的学习型 Agent 工作台。

当前版本已经完成一条可演示的学习闭环：
资料导入 -> 自动生成学习会话 -> 会话内 RAG 问答 -> 自测评分 -> 学习报告 -> 复习提醒。

## 当前能力

1. 支持导入 `pdf / docx / txt / md` 文件。
2. 支持导入单个网页链接，并抽取正文进入同一套学习入库链路。
3. 支持新建空白学习会话。
4. 支持“根据资料新建会话”和“导入当前会话”两种导入方式。
5. 支持自动生成会话名称、学习主题、学习目标。
6. 支持资料切块、向量入库、会话内检索问答。
7. 支持自动生成摘要、关键词、知识点、面试要点。
8. 支持把知识点转成复习项，并在问答时注入复习提醒。
9. 支持生成测验、提交答案、返回评分结果。
10. 支持把测验低分题自动沉淀成高优先级复习项。
11. 支持查看学习计划，生成“今天学什么 / 先复习什么 / 下一步问什么”。
12. 支持单页网页导入，也支持目录页批量导入同站多篇文章。
13. 支持查看学习报告，汇总资料、知识点、问答和最近一次测验表现。
14. 支持查看历史学习会话，并删除当前学习会话。
15. 支持流式回答、来源展示、复习提醒展示。

## 适合演示的亮点

1. 从本地文件学习助手升级成“多源学习资料工作台”。
2. 文件与网页资料共用同一条入库链路，后续继续扩展站点适配成本低。
3. 会话级隔离的 RAG 检索，回答更聚焦当前学习主题。
4. 问答、自测、错题回流、计划、报告已经形成更完整的学习闭环。
5. 保留多 Agent 架构基础，便于后续继续接评测和面试模式。

## 启动方式

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

当前 `requirements.txt` 已覆盖本地演示所需的核心依赖：
`FastAPI / Streamlit / Chroma / DashScope / OpenAI SDK / 文档解析 / 检索 / 网页抓取`。

### 2. 配置环境变量

至少需要：

```bash
DASHSCOPE_API_KEY=your_api_key
BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
```

如果未正确配置大模型，部分摘要、测验、报告能力会回退到规则生成版本，但基础链路仍可运行。

### 3. 启动后端

```bash
python Zero_RAG/Server.py
```

默认地址：

```text
http://127.0.0.1:8000
```

### 4. 启动前端

```bash
streamlit run Zero_RAG/Client.py
```

## 推荐演示流程

1. 先点“新建空白学习会话”，创建一个新的主题容器。
2. 上传一份文件，或导入一个网页链接。
3. 查看系统自动生成的会话名称、摘要、知识点和复习项。
4. 在“学习问答”里连续追问，观察流式输出、来源引用和复习提醒。
5. 切到“测验模式”生成一套题，在每道题下方填写答案后，点击页面底部的 `提交测验并评分`。
6. 查看系统把低分题自动写回高优先级复习项。
7. 切到“学习计划”查看“今天学什么 / 先复习什么 / 下一步问什么”。
8. 切到“学习报告”刷新复盘结果，展示本轮学习的进展、风险和下一步建议。

## 数据存储说明

1. `study_agent.sqlite3`
   学习会话、文档、摘要、知识点、复习项、测验数据。
2. `chat_history.sqlite3`
   聊天历史和线程状态。
3. `Zero_RAG/chroma_db`
   向量数据。
4. `uploaded_study_materials`
   上传资料的本地副本。

## 当前默认用户策略

当前前端为了避免“新开页面看不到旧会话”，默认固定为单机单用户模式。

位置：

1. `Zero_RAG/Client.py` 中的 `DEFAULT_USER_ID`
2. `Zero_RAG/Client.py` 中的 `ensure_user_id()`

如果要改回用户隔离：

1. 把 `DEFAULT_USER_ID` 改回动态生成策略。
2. 把 `ensure_user_id()` 改回“优先读取 query param，没有则生成 UUID”。
3. 后端接口不需要改，后端本来就是按 `user_id` 做学习会话隔离的。

## 当前交互说明

1. 学习会话在侧边栏选择。
2. 支持新建空白学习会话。
3. 文件和网页导入都支持：
   `根据资料新建学习会话`
   `导入当前会话`
4. 提问框按回车提交。
5. 回答为流式输出。
6. “会话概览”位于主区域上方，可折叠。
7. 主区域包含三个标签页：
   `学习问答`
   `测验模式`
   `学习计划`
   `学习报告`
8. 支持删除当前会话。
9. 测验模式支持可见的 `提交测验并评分` 按钮，提交后会展示总分、逐题反馈和改进建议。
10. 测验低分题会自动沉淀为高优先级复习项。
11. 侧边栏支持“目录页批量网页导入”，可限制最多导入篇数。
