# LearnOS

面向个人学习、资料问答、自测复盘和面试准备的学习型 Agent 工作台。

当前版本已经完成一条可演示的学习闭环：
资料导入 -> 自动生成学习会话 -> 会话内 RAG 问答 -> 回答质量评测 -> 模拟面试 -> 混合题型自测 -> 错题重练 -> 复习调度 -> 学习计划 -> 学习报告 -> 运行观测。

## 当前能力

1. 支持导入 `pdf / docx / txt / md` 文件。
2. 支持导入单个网页链接，并抽取正文进入同一套学习入库链路。
3. 支持新建空白学习会话。
4. 支持“根据资料新建会话”和“导入当前会话”两种导入方式。
5. 支持自动生成会话名称、学习主题、学习目标。
6. 支持资料切块、向量入库、会话内检索问答。
7. 支持自动生成摘要、关键词、知识点、面试要点。
8. 支持把知识点转成复习项，并在问答时注入复习提醒。
9. 支持生成测验、提交答案、返回评分结果。
10. 支持单选题、填空题、简答题混合测验。
11. 支持把测验低分题自动沉淀成高优先级复习项。
12. 支持独立错题本页面，按会话、分数、时间筛选错题，并支持错题重练。
13. 支持错题状态演进，记录 `retrying / improving / mastered`。
14. 支持复习调度队列，按优先级、到期状态、掌握度自动排序。
15. 支持查看并保存学习计划，生成“今天学什么 / 先复习什么 / 下一步问什么”。
16. 支持按当前学习进展重排学习计划优先级，并保留已完成项。
17. 支持勾选学习计划完成状态，并支持“只看未完成项”。
18. 支持单页网页导入，也支持目录页批量导入同站多篇文章。
19. 支持查看学习报告，汇总资料、知识点、问答和最近一次测验表现。
20. 支持最小可观测能力，可查看关键操作运行日志。
21. 支持查看历史学习会话，并删除当前学习会话。
22. 支持流式回答、来源展示、复习提醒展示。
23. 支持学习问答回答质量评测，记录准确性、依据性、完整性、清晰度和改进建议。
24. 支持模拟面试模式，按轮生成问题、逐轮评分、自动追问并输出总结。
25. 支持 Agent run / step 级运行观测，可查看每次问答或面试的步骤日志。
26. 支持学习问答 Query Rewrite，提升口语化问题和追问场景下的检索稳定性。
27. 支持标题增强分块，为网页与文档 chunk 补充章节标题和 heading path。
28. 支持检索调试可视化，可查看原始 query、改写 query、向量召回、BM25 召回与 rerank 结果。

## 适合演示的亮点

1. 从本地文件学习助手升级成“多源学习资料工作台”。
2. 文件与网页资料共用同一条入库链路，后续继续扩展站点适配成本低。
3. 会话级隔离的 RAG 检索，回答更聚焦当前学习主题。
4. 问答、自测、错题回流、计划、报告已经形成更完整的学习闭环。
5. 回答评测、模拟面试、复习调度、运行观测和可调试的 RAG 检索链路已经让系统更接近真实学习产品。

## 启动方式

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

当前 `requirements.txt` 已覆盖本地演示所需的核心依赖：
`FastAPI / Streamlit / Chroma / DashScope / OpenAI SDK / 文档解析 / 检索 / 网页抓取`。

### 2. 配置环境变量

至少需要：

```bash
DASHSCOPE_API_KEY=your_api_key
BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
```

如果未正确配置大模型，部分摘要、测验、报告能力会回退到规则生成版本，但基础链路仍可运行。

### 3. 启动后端

```bash
python Zero_RAG/Server.py
```

默认地址：

```text
http://127.0.0.1:8000
```

### 4. 启动前端

```bash
streamlit run Zero_RAG/Client.py
```

## 推荐演示流程

1. 先点“新建空白学习会话”，创建一个新的主题容器。
2. 上传一份文件，或导入一个网页链接。
3. 查看系统自动生成的会话名称、摘要、知识点和复习项。
4. 在“学习问答”里连续追问，观察流式输出、来源引用和复习提醒。
5. 切到“测验模式”生成一套混合题型测验，完成单选题、填空题和简答题后提交评分。
6. 查看系统把低分题自动写回高优先级复习项。
7. 切到“错题本”按分数、时间、会话筛选当前错题，并做一轮错题重练。
8. 切到“复习调度”查看系统自动排出的复习队列，并用 `Again/Hard/Good/Easy` 推进状态。
9. 切到“学习计划”查看、勾选并按当前进展重排“今天学什么 / 先复习什么 / 下一步问什么”。
10. 切到“回答评测”查看最近问答与面试回答的质量评分。
11. 切到“模拟面试”开始一轮面试问答，观察逐轮反馈、追问和总结。
12. 在“学习问答”或“运行观测”里打开“检索调试”，查看 query 改写、混合召回和 rerank 结果。
13. 切到“学习报告”刷新复盘结果，再到“运行观测”查看关键动作耗时、run 和 step 详情。

   聊天历史和线程状态。
3. `Zero_RAG/chroma_db`
   向量数据。
4. `uploaded_study_materials`
   上传资料的本地副本。

## 当前默认用户策略

当前前端为了避免“新开页面看不到旧会话”，默认固定为单机单用户模式。

位置：

1. `Zero_RAG/Client.py` 中的 `DEFAULT_USER_ID`
2. `Zero_RAG/Client.py` 中的 `ensure_user_id()`

如果要改回用户隔离：

1. 把 `DEFAULT_USER_ID` 改回动态生成策略。
2. 把 `ensure_user_id()` 改回“优先读取 query param，没有则生成 UUID”。
3. 后端接口不需要改，后端本来就是按 `user_id` 做学习会话隔离的。

## RAG V1.2 更新

当前已完成 `RAG V1.2`，主要新增了三项能力：

1. `Multi-Query / 子问题分解`
   学习问答会在 Query Rewrite 之后继续做多查询扩展，针对对比题、原因题、总结题自动拆成 2 到 4 个检索子问题，提升复杂问题召回覆盖率。
2. `Parent-Child 多粒度检索`
   检索阶段优先命中细粒度 chunk，进入生成前会按 `document_id + heading_path` 回填同章节父级上下文，兼顾定位精度和上下文完整性。
3. `Context Compression`
   Rerank 后新增上下文治理，包含近重复 chunk 去重、单片段压缩和总上下文长度裁剪，减少噪声与 token 浪费。

现在在“学习问答”和“运行观测”里，除了能看到原始 query、改写 query、向量召回、BM25 和 rerank，还能看到：

1. `Multi-Query` 策略与扩展出的检索子问题
2. `Parent-Child` 回填次数
3. `Context Compression` 的去重、截断和最终上下文长度统计

## RAG V1.3 更新

当前已经完成 `RAG V1.3` 的第一版检索评测闭环，新增了：

1. 默认评测集 `rag_eval_cases.json`
2. 会话级自动评测集生成
3. 检索评测接口：
   - `GET /study_sessions/{session_id}/rag/eval_dataset_template`
   - `GET /study_sessions/{session_id}/rag/eval_cases`
   - `POST /study_sessions/{session_id}/rag/evaluate`
4. 检索指标输出：
   - `MRR`
   - `Recall@1 / Recall@3 / Recall@5`
   - `Top-k 命中情况`
   - `low_quality_cases`
5. 前端 `RAG评测` 标签页，可直接预览评测集、运行评测、查看低质量 query 和逐条检索调试信息

现在 LearnOS 的 RAG 主链路可以概括为：

1. `RAG V1.1`
   Query Rewrite、标题增强分块、检索调试可视化
2. `RAG V1.2`
   Multi-Query、Parent-Child、Context Compression
3. `RAG V1.3`
   检索评测集、Recall@k / MRR、低质量 query 分析
