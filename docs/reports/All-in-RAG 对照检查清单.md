# All-in-RAG 对照检查清单

> 对照来源：Datawhale All-in-RAG  
> 地址：https://datawhalechina.github.io/all-in-rag/#/  
> 当前项目：LearnOS  
> 更新时间：2026-04-28

## 总体结论

LearnOS 已经完成了学习场景下 RAG 产品主线的 V2 第一版，覆盖了“资料导入 -> 文本切分 -> 混合检索 -> 重排 -> 上下文组装 -> 流式生成 -> 质量评测 -> 质量看板 -> 学习闭环”的核心链路。

如果以 All-in-RAG 的完整知识版图作为参照，LearnOS 当前并不是全部完成。已经完成的是通用 RAG 与 Advanced RAG 中最贴合个人学习助手场景的部分；GraphRAG、多模态 RAG、Text2SQL、生产级可观测与自动化回归门禁等方向仍属于后续扩展项。

## 下一阶段建议优先级

### P0：优先推进

1. RAG 回归评测工程化
   - 建固定 benchmark case。
   - 每个 case 记录问题、期望命中文档、期望 chunk、参考答案要点。
   - 自动输出 MRR、Recall@1、Recall@3、Answer groundedness。
   - 后续作为提交前质量门禁。

2. 低质 Query 闭环
   - 给低质样本增加状态：待处理、已修复、忽略。
   - 支持一键加入回归评测集。
   - 支持查看某类低质问题被哪次策略修复。

3. 引用可信度与幻觉拦截
   - 检查回答中的关键断言是否能被检索内容支撑。
   - 如果资料中没有依据，应明确提示“当前资料未覆盖”。
   - 增加引用覆盖率指标。

4. 学习计划 / 测验专用检索增强
   - 计划生成优先检索未掌握知识点、复习项、错题、低分测验。
   - 测验生成优先检索高重要度知识点和历史薄弱点。

### P1：随后推进

1. RAG 质量看板升级
   - 增加耗时趋势、路由效果趋势、低质原因趋势。
   - 展示不同问题类型下的 MRR 和 Recall。
   - 展示 rerank 前后效果对比。

2. 缓存与成本优化
   - Embedding 缓存。
   - Query rewrite 缓存。
   - 检索结果缓存。
   - Token 成本估算。

3. 网页导入增强
   - 动态网页抓取兜底。
   - 更强正文抽取。
   - 更好的代码块、表格、图片说明保留。

### P2：长期扩展

1. GraphRAG / 概念图谱
   - 基于知识点、错题、复习项构建概念关系图。
   - 支持“我哪里没学懂”的路径分析。

2. 多模态 RAG
   - 支持截图、课件图片、图表 OCR。
   - 适合扩展到课程资料学习场景。

3. Text2SQL
   - 当前不是 LearnOS 主线，除非后续要支持结构化学习数据分析，否则不建议优先做。

## 简历表达建议

可以把当前 RAG 能力概括为：

> 构建面向个人学习场景的 Advanced RAG 系统，支持本地文件与网页资料导入、语义分块、Hybrid Retrieval、Rerank、Query Rewrite、Multi-Query、Parent-Child 上下文回填、问题类型识别与动态检索路由，并基于 MRR、Recall@1、低质样本沉淀和 RAG 质量看板形成可观测、可评估、可持续优化的 RAG 闭环。

从零独立设计并落地一套面向个人学习场景的AI学习工作台，支持文件/网页资料导入、会话级RAG问答、自动摘要、混合题型测验、错题回流、复习调度、学习计划、学习报告、回答评测与模拟面试。系统以学习会话为核心组织单位，打通“资料导入→理解问答→自测评估→错题回流→复习调度→计划与报告”的学习闭环，并重点建设了可观测、可评测、可持续调优的RAG检索链路。
