# LearnOS 项目架构框图

> 项目名称：基于 RAG 与学习状态调度的 AI 学习工作台 LearnOS  
> 当前数据层：Docker MySQL + ChromaDB  
> 更新时间：2026-04-30

## 10. 建议展示拆分

如果用于答辩、论文或 PPT，建议拆成四张核心图：

1. 系统总架构图。
